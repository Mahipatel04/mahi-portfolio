# Spendwise

A personal monthly expense tracker. Set a take-home salary and category limits, then record income and expenses to see your remaining balance, spending breakdown, and weekly pace.

## Run locally

Open this folder in Visual Studio Code and launch `index.html` with Live Server. No build step or package installation is required.

## Features

- Monthly salary plan and editable category budgets
- Add, edit, and delete income and expense transactions
- Monthly income, spending, remaining balance, and weekly pace summaries
- Category breakdown and budget progress
- Search and category filters
- CSV export for the selected month
- Responsive desktop and mobile layout

## Privacy

Data is stored in this browser's local storage. The app does not connect to a bank or send financial information to a server. Clearing browser data removes the saved entries. This is a personal tracking tool, not financial advice.
