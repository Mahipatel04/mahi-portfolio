# Mahi Patel — Portfolio

A responsive, single-page portfolio highlighting Mahi's application development co-op experience, education, technical skills, and three portfolio projects.

## Preview locally

Open `index.html` in a modern browser. The page uses plain HTML and CSS, with no build step or package installation. Google Fonts are loaded when an internet connection is available; system font fallbacks are included.

## Sections

- Introduction and contact links
- About and professional experience
- Education and toolkit
- Ticket Desk, Ticket Desk API Tests, and Ticket Insights

All project descriptions link to their public GitHub repositories. Project previews are visual mockups and sample figures, not live connections to those applications.
